### Linting and Formatting Tools

# Full Installation

```bash
npm install --save-dev eslint prettier eslint-plugin-react eslint-config-prettier eslint-plugin-prettier prettier-plugin-tailwindcss
```

# ESLint Installation

```bash
npm install --save-dev eslint
```

# ESLint Plugin Installation

```bash
npm install --save-dev eslint-plugin-react eslint-config-prettier eslint-plugin-prettier
```

# Prettier Installation

```bash
npm install --save-dev prettier
```

# Prettier Plugin Installation

```bash
npm install --save-dev prettier-plugin-tailwindcss
```


## Scripts

```json
"scripts": {
  "lint": "eslint .",
  "format": "prettier --write ."
}
```
Run

```bash
npm run lint     # Run ESLint
npm run format   # Format code with Prettier
```
